One fortune cookie message for a software engineer, 96 characters, written for make.fun's "Fortune Cookie Funnies for Engineers" bounty, $2 in USDC.

> You will inherit code with no comments, written by a genius who left no map. The genius was you.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` (Node 22, standard library only) copies `fortune.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The fortune is a single line of at most 120 characters, judged pairwise against the other entries.
